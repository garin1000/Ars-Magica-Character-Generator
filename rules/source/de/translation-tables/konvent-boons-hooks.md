# Ars Magica Definitive Edition – Konventsvorzüge und -haken / Covenant Boons and Hooks

**Legende:**
- (Lat.) = Lateinischer Begriff, wird unübersetzt beibehalten
- → Konventsbegriffe allgemein: [konvent.md](konvent.md)

> **Nur Begriffe.** Punktwerte, Wirkungen und Bedingungen der Vorzüge und Haken stehen in den Basisregeln, Abschnitte *Haken*, *Kleine Haken*, *Große Haken*, *Vorzüge*, *Kleine Vorzüge* und *Große Vorzüge* (Kapitel 6: Konvente, *Maßgeschneiderte Konventserstellung*). Die Liste umfasst nur die Einträge des Grundregelwerks; *Covenants* enthält viele weitere. Die früher hier geführten Beschreibungen und Kategorien waren vielfach falsch (Sachprüfung 2026-10-03, `lektorat/tabellen-sachpruefung-reputation-qualitaeten-konvent.md`) und sind entfernt oder berichtigt. Die Anmerkungen sind nur Orientierung zur Bedeutung.

## Haken / Hooks

### Kleine Haken / Minor Hooks

| Englisch (EN) | Deutsch (DE) | Anmerkung |
|---|---|---|
| Contested Resource | Umstrittene Ressource | Cov: Resources |
| Favors | Gefälligkeiten | Cov: External |
| Hermetic Politics | Hermetische Politik | Cov: External |
| Monster | Ungeheuer | Cov: Surroundings; ein mächtiges Wesen lebt in der Nähe des Konvents |
| Poverty | Armut | Cov: Resources |
| Protector | Beschützer | Cov: Surroundings; **der Konvent** beschützt etwas (Dorf, Hain, schwächeren Konvent) – nicht „hat einen Beschützer“ |
| Regio | Regio | Cov: Site; ein Regio auf dem Gelände, der Konvent liegt nicht darin |
| Rival | Rivale | Cov: External |
| Road | Straße | Cov: Site; wichtige weltliche Straße, Fluss- oder Seeroute |
| Superiors | Vorgesetzte | Cov: Residents; die Spielercharaktere leiten den Konvent nicht |
| Urban | Städtisch | Cov: Site; Marktflecken |

### Große Haken / Major Hooks

| Englisch (EN) | Deutsch (DE) | Anmerkung |
|---|---|---|
| Beholden | Verpflichtet | Cov: External |
| Castle | Burg | Cov: Buildings; der Konvent **besitzt** eine Burg oder ein Bauwerk, das der örtliche Adel als Bedrohung ansieht |
| Monster | Ungeheuer | Cov: Site oder Surroundings; ein mächtiges Wesen lebt im Konvent |
| Mundane Politics | Weltliche Politik | Cov: External |
| Poverty | Armut | Cov: Resources |
| Regio | Regio | Cov: Site; ein Regio auf dem Gelände, der Konvent liegt nicht darin |
| Rival | Rivale | Cov: External |
| Road | Straße | Cov: Site; ein mystischer Pfad, über den übernatürliche Wesen zum Konvent kommen |
| Superiors | Vorgesetzte | Cov: Residents; ranghöhere Mitglieder des Konvents können den Spielercharakteren Befehle erteilen |
| Unknown | Unbekannt | keine Cov-Kategorie; ein Spieler leitet diesen Haken als Spielleiter (nur im Troupe-Stil) |
| Urban | Städtisch | Cov: Site; Stadt |
