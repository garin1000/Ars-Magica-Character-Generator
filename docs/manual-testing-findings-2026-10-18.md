| 11 | Rules: Later-Life XP | A magus can buy **Magic Theory** with Later-Life points. **The rules don't allow it:** "the character gains 15 experience points per year, which may be placed in any Abilities, as long as the character has a Virtue that permits her to learn those Abilities. Academic, Arcane, and Martial Abilities require a Virtue, as do Supernatural Abilities" (`ArMDE:2462`). Magic Theory is Arcane (`ArMDE:7720-7722`). Hermetic Magus grants no Arcane access (`ArMDE:4142`); the magus learns Magic Theory in Apprenticeship. Later-Life (and early-childhood) XP may buy restricted categories only under an authorizing Virtue (e.g. Arcane Lore, `ArMDE:3505`). Check how the engine gates restricted categories per life-stage pool (wrong rules output, so HIGH). Same check for Academic/Martial. **The fix must keep Apprenticeship and post-Gauntlet points able to buy Magic Theory (and the other restricted categories).** Apprenticeship: "These experience points can be spent on Arts or Abilities, including Arcane, Academic, and Martial Abilities. Note that magi can only spend experience points on Arcane, Academic and Martial Abilities before apprenticeship if they have a Virtue which allows them to do so" (`ArMDE:2505`). Post-Gauntlet: "Each point can be an experience point in an Art or Ability" (`ArMDE:2541`). So the restriction applies only to the pools *before* apprenticeship (early childhood and Later Life). **Scope:** all twelve Arcane Abilities are affected the same way (Code of Hermes, Dominion/Faerie/Infernal/Magic Lore, Enigmatic Wisdom, Faerie Magic, Finesse, Heartbeast, Magic Theory, Parma Magica, Penetration), and so are the other gated categories. **First analysis (2026-10-18):** the engine's Later-Life pool (`effective/xp.rs::later_life_pool`) already excludes every gated category unless the entity holds an *explicit* authorization (D43), so the XP solve itself looks correct. The defect is therefore probably where the funding is **shown or chosen** (the Abilities tab's pool attribution, or the character carries an authorizing Virtue). Reproduce first, with a save from Norbert if possible. **Confirmed 2026-10-18:** decisive test added (`validation/life_stage.rs::magic_theory_without_authorization_cannot_be_funded_once_apprenticeship_is_exhausted`) — a magus whose gated demand (academic+arcane, 255 XP) exceeds the apprenticeship pool (240 XP) correctly raises `CODE_NOT_ENOUGH_XP`; `later_life`'s spare 75 XP cannot absorb the shortfall since it excludes gated categories without authorization. Engine is correct. **Root cause is UI attribution**, not an engine bug: `XpBar.svelte` (Agent B's territory) shows an aggregate "Later Life: X/Y used" with no per-pool breakdown, so a correctly apprenticeship-funded Magic Theory purchase can misread as Later-Life-funded. No engine/UI fix made; filed as a UI-clarity note for Agent B/Norbert. | done |
