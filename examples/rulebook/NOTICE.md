# Example characters — licensing and attribution

This `examples` folder ships with the Ars Magica Character Generator and holds
the character templates printed in the Ars Magica core rulebook — the grog,
companion and magus templates — as save files (`.armc`) the application opens
with File > Open. This notice is the attribution that travels with them.

In short: the **format** is the project's own work and is MIT-licensed; the
**Ars Magica content** inside each file — the template's name, statistics,
Virtues, Flaws, Abilities, spells and personality traits, transcribed from the
rulebook — belongs to Atlas Games and is licensed under CC BY-SA 4.0.
Redistributing or adapting that content keeps it under CC BY-SA 4.0 with
attribution preserved.
